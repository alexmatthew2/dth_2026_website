## The Disadvantages of Open Source Software 

There are genuine disadvantages to open source software which make it difficult to recommend unreservedly for everyday use for everyone. However, these disadvantages are not necessarily obvious, while those disadvantages that seem to be obvious do not necessarily hold true. 

A myth about open source software, for example, is that it is less secure due to the code being publicly accessible. However, such claims do not hold up to reality. Linux operating systems, on aggregate, are actually less vulnerable to computer virus transmissions through vectors such as email attachments and malicious URLs (Wallen 2010). There are several reasons for this, one being that .exe files do not work on Linux, another that there is no universal equivalent format to .exe on Linux (instead this is split into .deb, .rpm, .bin, etc.) and finally that installable files must be approved prior to installation with a root or sudo password. Practically speaking, viruses which Linux operating systems are vulnerable to are almost nonexistent, and while some of this can be attributed to its relative lack of popularity comparative to Windows systems, for an ordinary user living in the present moment, this still translates to a higher level of security. 

A more serious disadvantage for open source software is the compatability issue. Proprietary, commercial software is widespread and oftentimes required for jobs and schooling, and frequently neglects to support open source programs or operating systems. Part of this can be attributed to the fact that open source software tends to have a smaller market share than its competitors, but it would not be surprising either if companies deliberately refused to support software that is a free competitor to their own products. An example of this is actually Wiseflow’s device-monitoring software. It does not support Linux, so in order to pass my exams last winter, I needed to borrow a different computer. 

Wallen, J. (2010, February 9). Myth busting: Is linux immune to viruses? Linux.com. https://www.linux.com/training-tutorials/myth-busting-linux-immune-viruses/
